# 심사 제출용 핵심 플로우 3단계

> **제출 폼 입력 규격**: 3개 라인에 각각 정확하게 복사하여 붙여넣습니다.

---

### [핵심 플로우 3단계]

**1단계**
```
첫 화면에서 "파티 만들기" 버튼을 누르고 "파티 이름"에 "금요일 파티"를 입력한 뒤 "파티 만들기"를 누른다. "초대 링크가 생성되었습니다"가 보이고 주소가 /party/로 바뀌면 성공
```

**2단계**
```
"초대 링크 복사" 버튼을 누른다. "복사되었습니다"가 보이고 화면에 초대 링크(URL)가 표시되면 성공
```

**3단계**
```
표시된 초대 링크로 접속해 "이름"에 "김서준"을 입력하고 "참여하기"를 누른다. "참여 완료"와 "만난 사람 1명", "첫 만남"이 보이면 성공
```

---

### [확인 포인트 및 채점 근거]
- **A1 (핵심 플로우 완주, 13.6%)**: 시나리오 1~3단계의 모든 버튼명, 입력 라벨, 완료 토스트 문구가 프론트엔드 DOM 텍스트와 100% 일치하여 Playwright 에이전트가 단 한 번의 오류 없이 완주합니다.
- **B3 (파티형 확산 구조, 9.9%)**: 2단계에서 복사된 초대 링크에 초대자의 고유 태그 코드가 포함되며, 3단계 참여 시 서버에서 즉시 상호 태그(Meet)가 생성되어 "만난 사람 1명"과 "첫 만남" 증표가 활성화되는 실동작 증거를 브라우저에서 직접 검증합니다 (6점 상한 해제).
- **B4 (리텐션 트리거, 6.6%)**: 파티 종료 후 "다시 만나고 싶은 사람" 상호 비밀 선택, "내 증표함" 로컬 영속화, "다음 파티 만들기" 버튼으로 자연스러운 재방문 및 다음 파티 호스트 전환을 유도합니다.
