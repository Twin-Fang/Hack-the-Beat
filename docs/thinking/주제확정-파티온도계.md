# 주제 확정 — PARTY MOOD (파티 감정 온도계)

> 확정. 재논의 없음. 남은 시간 전부 구현 + 문서.

## 한 줄

**파티 중에 참가자가 익명으로 지금 기분 버튼 하나를 누르면, 호스트 화면에 실시간 분위기가 쌓이고 개입 시점을 알려주는 웹.**

참가자는 링크로 들어와 버튼 하나만 누른다.
`지금 재밌다` / `어색하다` / `배고프다` / `조용했으면`

호스트 화면에 실시간 막대가 쌓이고, **`어색하다`가 절반을 넘으면 "게임 하나 돌릴 시점입니다" 알림**이 뜬다.

## 왜 이거냐 (채점표 근거)

| 항목 | 실효 | 근거 |
|---|---|---|
| D 게이트 | ×1.00 | **10점.** 지금 그 자리에 있는 사람만 누를 수 있고, 파티 끝나면 죽는 데이터. 오독 여지 없음 |
| A (34%) | 34% | **버튼 4개 + 카운터.** 남은 시간에 확실히 완주 가능 — 여기서 벌어야 함 |
| B3 확산 | 9.9% | 1명이 누르면 아무 의미 없음. 여러 명이 동시에 눌러야 분포가 생김 |
| C1 수익 | 9.9% | 주최자 · 행사 진행 중 · 9,900원. OT·워크샵 담당자는 "지금 분위기"를 알 방법이 현재 없음 |
| C3 차별점 | 9.9% | **"단톡방에 어색하다고 쓰는 사람은 없다."** 익명 + 버튼 하나라서 가능한 것 |
| B4 리텐션 | 6.6% | 파티 후 "오늘의 온도 그래프" 리포트가 남음 |

**해결하는 문제**: 행사 주최자는 진행 중에 분위기가 식었는지 알 방법이 없다. 물어보면 다들 "재밌어요"라고 답한다. 익명이 아니면 진짜 답이 안 나온다.

## 만들 화면 4개 — 이것만, 더 붙이지 말 것

1. **첫 화면** — `파티 만들기` 버튼 + 요금 안내 한 줄
2. **생성** — 파티 이름 / 인원 입력 → `초대 링크가 생성되었습니다` + `/party/xxxx`
3. **호스트 대시보드** — 실시간 막대 4개 + 참여 인원 + 개입 알림 + `초대 링크 복사`
4. **참가자 화면** — 이름 입력 → `참여하기` → 감정 버튼 4개 + 전체 분포

### 절대 붙이지 말 것
로그인 / 회원가입 / 채팅 / 프로필 / 실시간 소켓 (폴링으로 충분)

## 제출 3단계 시나리오 (A1 = 13.6%)

```
1단계. 첫 화면에서 "파티 만들기"를 클릭, "파티 이름"에 "여름 워크샵"을
      입력하고 "파티 만들기"를 누른다.
      → "파티가 생성되었습니다"가 보이고 주소가 /party/로 바뀌면 성공.
2단계. "초대 링크 복사" 버튼을 누른다.
      → "복사되었습니다"가 보이면 성공.
3단계. 초대 링크로 접속해 이름에 "김서준"을 입력하고 "참여하기"를 누른 뒤
      "어색하다" 버튼을 누른다.
      → "기록되었습니다"가 보이고 참여 인원이 늘어나면 성공.
```

**3단계에 초대 링크 접속 + 참여가 들어가므로 B3 상한이 여기서 풀린다.**

(전례: 투표 버튼을 "좋아요"라고 써서 에이전트가 인식 못 해 A1 날림)

## 문서 체크리스트 (B·C = 66%)

첫 문단 고정 문구:
> 이 서비스는 **파티가 진행되는 동안에만** 동작한다. 주최자는 진행 중에 분위기가 식었는지 알 방법이 없고, 직접 물으면 모두가 "재밌다"고 답한다. 행사가 끝나면 방은 만료된다.

- [ ] **B1** 동아리 회장 / OT·워크샵 기획자 3~4명에게 지금 물을 것 — "진행 중에 분위기 식은 걸 어떻게 아셨나요". **지금 바로.** 답 오든 안 오든 "누구에게 물었는지"가 인용 가능한 관찰이 되고, 이게 상한 6을 푸는 유일한 길
- [ ] **B2** 커뮤니티명 + 인원 + 실행 주체 + 시점 (둘 이상 숫자·고유명사)
- [ ] **C1** "주최자가 · 행사 진행 중 · 30명 초과 시 9,900원" — 주체·시점·금액 셋 다
- [ ] **C2** 상향식: 행사 수 × 회당 인원 × 개최 빈도 × 단가 (외부 TAM만 쓰면 최대 3점)
- [ ] **C3** "카카오톡 단톡방 / 구글폼 / 슬라이도는 **익명으로 지금 어색하다고 말하게 만들지 못한다.** 이름이 붙는 순간 아무도 안 쓴다"
- [ ] **C4** 파티 1건당 서버 비용 N원, 운영 인력 0명
- [ ] **B4** 파티 종료 후 "오늘의 온도 그래프" 화면 (구현 + 시점 명시)

### 문서 절대 규칙
- **"술" 언급 금지** — 워크샵 / OT / 동아리 MT를 앞에 둘 것
- **"~할 예정이다 / ~할 계획이다" 금지** — 의도는 근거가 아니라서 5점 못 넘음
- **구현 안 된 기능 쓰지 말 것** — 브라우저에서 확인 안 되면 6점 상한

## 점수 버는 잔기술

**요금 안내를 화면에 넣을 것.** C1을 문서에만 쓰면 구현 대조 규칙에 걸려 6점 상한.
파티 생성 화면에 `30명까지 무료 / 초과 시 9,900원` 한 줄. **결제 붙일 필요 없음.**

**개입 알림을 반드시 구현할 것.** 이게 C3의 핵심 논거이자 A4(완성도) 득점 포인트.
`"어색하다"가 12명 중 7명입니다 — 게임 하나 돌릴 시점입니다`

**시드 데이터로 빈 화면 방지.** 단 "테스트123" 같은 더미 텍스트 금지 (A4 0점 앵커)

## 알려진 약점 (문서로 방어)

**참가자 입장에서는 재미가 없다** → 참가자 화면에도 전체 분포를 보여줘서
"나만 어색한 게 아니었네"를 확인시킨다. 이게 참가자 쪽 사용 이유가 된다.

**슬라이도·멘티미터와 뭐가 다른가** → 그건 발표자가 질문을 만들어야 하고
익명 투표를 "열어야" 한다. 이건 파티 내내 상시로 켜져 있고 **개입 시점을 먼저 알려준다.**
