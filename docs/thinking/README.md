# thinking — 팀원별 주제 제안

각자 생각하는 주제를 **파일 하나씩** 올리는 폴더. 형식 자유, 아래 항목만 들어가면 된다.

## 파일 규칙

- 파일명: `<주제명>.md` 또는 `<이름>-<주제명>.md`
- 남의 파일은 수정하지 말고 댓글처럼 자기 파일에 의견을 적는다
- 확정된 주제는 파일 맨 위에 `확정` 표시

## 들어가야 할 것 (심사 기준 [judging-criteria.md](../judging-criteria.md) 1절 "아이템 선정 필터")

1. **한 줄** — 파티 전·중·후 중 어느 순간의 어떤 불편을 푸는가
2. **초대/동반 참여 없이는 안 되는 이유** (B3)
3. **단톡방·인스타·구글폼으로 안 되는 이유** (C3)
4. **다시 올 이유** (B4)
5. **제출 3단계 시나리오 초안** — 화면 텍스트 인용
6. **남은 시간에 완주 가능한가** (A1이 13.6%)
