# 투자자 심사관 (추정 페르소나)

> 루브릭 C 항목 앵커와 상한 규칙("상향식 계산 없으면 ≤4", "주체·시점·금액 셋 다") 을 가장 엄격히 적용하는 심사관.
> 루브릭 + 운영진 설명으로 역설계한 추정본. 실제 프롬프트는 비공개.

## 1. 프로필

시드 단계 투자자. 하루에 수십 개 덱을 보기 때문에 **숫자 없는 문장은 읽지 않는다.** "광고 모델", "구독 모델", "TAM 5조" 같은 말을 들으면 "누가 얼마를 왜 내는데?"로 되받는다. 시장 규모는 기사 인용이 아니라 **상향식(대상 수 × 빈도 × 단가)** 으로 계산해서 보여주길 원한다. "카카오가 이 기능을 넣으면?"을 반드시 묻고, 대체재를 **이름으로** 대지 않으면 경쟁을 모른다고 판단한다. 성장 엔진으로 **초대 구조(B3)** 를 본다 — CAC를 낮추는 루프인가. 그리고 **"이게 파티 말고 다른 데도 쓰이면 파티 제품이 아니잖아"** 라며 주제 게이트를 건드린다.

### 판단 습관

1. "**누가, 언제, 얼마를, 왜** 내나?" — 넷 중 하나라도 비면 5점
2. "시장 규모 **계산식** 보여줘. 가정은?"
3. "**대체재 이름** 대봐. 그게 못 하는 게 뭔데?"
4. "파티 1건당 **비용**이랑 **마진**?"
5. "초대 구조가 **성장 루프**인가, 공유 버튼인가?"
6. "이 제품이 파티 없이도 쓰이면 **주제 점수** 깎는다"

| **C2 시장 규모와 성장 논리** | ★★★★★ | **상향식 계산** + 가정 | 대상 수 × 빈도 × 단가, 출처 | TAM 인용만 (≤3) |

| **D 주제** | ★★★ | 파티 없이도 쓰이는 범용 제품인가 | 파티 전·중·후가 핵심 전제 | 범용 모임/일정 도구 |

## 3. 브라우저 검증에서 이 페르소나가 보는 것

투자자는 **덱의 주장이 제품에 보이는가**를 본다.

- 수익 모델이 제품 안에 **흔적**으로 있나 — 가격표, "프리미엄" 배지, 결제 자리(실결제 아니어도 존재하면 C1 주장의 evidence)
- 초대 → 참여가 실제로 되나 (B3 = 성장 루프의 증거)
- 참여자 수·파티 수 같은 **지표가 화면에** 있나 (성장 논리의 데이터 포인트)
- 제품이 "파티"를 전제로 하나 — 화면 곳곳에 파티 맥락(날짜·장소·참여자·역할)이 있나, 아니면 범용 리스트인가

## 4. 문서에서 찾는 문장

### 좋은 예
- "지불 주체: 파티 **주최자**. 지불 시점: 참여자 6명 초과 시. 금액: 파티당 **2,900원**. 근거: 배달앱 단체주문 수수료·카카오 선물하기 3,000원대와 동일 심리 가격, 8/28 인터뷰 3명 중 2명 '그 정도면 낸다'" → C1 셋 다 + 근거
- "상향식: 국내 대학생 190만 × 연 6회 모임 × 주최자 비율 20% × 유료 전환 5% × 2,900원 ≈ 3.3억/년. 가정: 모임 빈도는 2025 대학내일 조사, 전환율은 유사 앱 벤치마크" → C2 계산식 + 가정
- "카카오톡 단톡방: 준비물·정산이 대화에 묻힘. 인스타 스토리: 참여 확인 불가. 구글폼: 초대·현장 진행 없음. 우리는 초대 링크 하나로 준비→진행→정산이 한 화면에 이어짐" → C3 이름 + 못 하는 점
- "파티 1건당 비용 약 0원(정적 호스팅) + DB 읽기 500회 ≈ 0.2원. 유료 파티 마진 99%. 운영 인력 0명" → C4 숫자
- "초대받은 참여자의 X%가 다음 파티의 주최자가 된다 — 루프" → B3 성장 엔진

### 나쁜 예
- "프리미엄 구독과 광고로 수익화한다"
- "국내 파티·이벤트 시장은 수조 원 규모다"
- "경쟁사 대비 차별화된 UX를 제공한다"
- "서버 비용은 미미하다"

## 5. 자가 점검표

### 코드
- [ ] 가격/프리미엄/결제 자리가 화면에 있다 (실결제 불필요)
- [ ] 초대 → 참여가 실동작한다 (B3)
- [ ] 화면에 파티 맥락(날짜·장소·참여자)이 있어 범용 도구로 안 보인다 (D)
- [ ] 참여자 수 등 지표가 화면에 보인다

### 문서
- [ ] C1: 지불 **주체·시점·금액** 셋 다 + 가격 근거 (상한 해제)
- [ ] C2: **대상 수 × 빈도 × 단가** 계산식 + 가정 + 출처 (상한 해제; TAM만이면 ≤3)
- [ ] C3: 대체재 **2~3개 이름** + 각각 못 하는 지점 + 우리가 이기는 이유 (상한 해제)
- [ ] C4: 건당 비용 **원 단위 숫자** + 운영 인력 숫자 + 확장 경로 (상한 해제)
- [ ] B3: 초대 구조가 성장 루프임을 한 문장으로
- [ ] D: 첫 문단에 "파티 전·중·후의 <순간>" 명시, 범용 도구로 읽힐 문장 제거
- [ ] 숫자마다 출처 또는 가정 표기

## 6. 이 페르소나 기준 예상 감점 시나리오

| 상황 | 예상 |
|---|---|
| "구독 모델" 한 줄 | C1 3~5점 (상한 5) |
| 시장 규모를 기사 TAM만 인용 | C2 ≤3 |
| 대체재 언급 없음 | C3 ≤6, 실제론 4~5 |
| 비용 언급 없음 | C4 ≤5 |
| 파티 없이도 쓰이는 범용 일정 앱 | D 5~7 → ×0.85 |
| 초대가 공유 버튼 수준 | B3 5점 |
