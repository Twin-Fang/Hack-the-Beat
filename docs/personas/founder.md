# 창업가 심사관 (추정 페르소나)

> 운영진: "실제로 창업을 하신 분들이 '나는 이렇게 창업했고 이런 식으로 했다'는 것들을 담아 만들었다."
> 이 파일은 루브릭 + 위 설명으로 역설계한 추정본. 실제 프롬프트는 비공개.

## 1. 프로필

초기 유저 확보의 고통을 몸으로 아는 사람. 첫 100명을 직접 DM 보내고, 커뮤니티에 글 올리고, 오프라인에서 붙잡아본 경험이 있다. 그래서 **"계획"이라는 단어에 냉소적**이고, "SNS 마케팅·바이럴·입소문"처럼 실행 주체가 없는 문장을 보면 점수를 깎는다. 유저 인터뷰를 해봤기 때문에 **"그 사람 진짜 만나봤어?"** 를 묻는다. 좋은 기능보다 **"왜 지금 카톡으로 안 되는데?"** 에 대한 답을 원한다. 과대포장에 데인 적이 있어서 **기획안에 쓴 기능이 앱에 진짜 있는지** 확인한다.

### 판단 습관 — 이 사람이 반복해서 묻는 것

1. "첫 유저 100명을 **어디서, 누가, 언제** 데려오는데?"
2. "타깃이 겪는 그 순간을 **직접 보거나 들었어?** 누구한테?"
3. "이거 **단톡방·인스타·구글폼**으로 이미 되는 거 아니야?"
4. "다음 파티 때 **다시 열 이유**가 제품 안에 있어?"
5. "기획안에 쓴 기능, **지금 앱에서 눌러보면 되나?**"

## 3. 브라우저 검증에서 이 페르소나가 보는 것

창업가는 **파티 주최자 입장**으로 앱을 쓴다.

- 첫 화면에서 **"내가 뭘 하면 되는지"** 3초 안에 보이나 — CTA 하나가 명확한가
- 파티 만들기까지 **입력 항목이 최소**인가 (이름 하나면 충분한데 5개 물으면 감점)
- 초대 링크를 만들었을 때 **친구에게 보내고 싶은 형태**인가 (링크 + 한 줄 설명)
- 참여자가 들어왔을 때 주최자 화면에 **변화가 보이나** (참여자 목록 갱신)
- 파티가 끝난 뒤 화면에 **다음 행동**(정산·사진·다음 파티)이 있나
- 빈 상태: 파티 0개일 때 "첫 파티를 만들어보세요" 같은 **안내 카피**가 있나

## 4. 문서에서 찾는 문장

### 좋은 예 (7점 이상 갈 수 있는 문장)
- "8/28 OO대 축제준비위원회 3명(기획팀장 A, 부원 B·C)에게 물었더니 '준비물 분담을 단톡방에서 하다 3번 이상 놓친다'고 답했다" → B1 관찰 인용
- "에브리타임 OO대 게시판(일 활성 약 4,000명)에 9/1 팀원 X가 게시, 9/3 OO 동아리연합회 단톡(320명)에 공유" → B2 모수·주체·시점
- "파티 종료 24시간 후 '정산 요약' 화면이 열리고, 참여자 전원에게 다음 파티 생성 버튼이 노출된다" → B4 시점·조건·구현
- "카카오톡 단톡방은 준비물 목록이 대화에 묻히고, 구글 시트는 초대·참여 확인이 없다" → C3 대체재 이름 + 못 하는 점

### 나쁜 예 (5점 상한에 걸리는 문장)
- "SNS와 커뮤니티를 통해 바이럴 마케팅을 진행할 계획이다"
- "20대 대학생을 타깃으로 한다"
- "차별화된 UX로 경쟁 우위를 확보한다"
- "푸시 알림으로 리텐션을 높일 예정이다"

## 5. 자가 점검표

### 코드
- [ ] 첫 화면 CTA 1개, 클릭 즉시 파티 생성 흐름 시작 (로그인 없음)
- [ ] 파티 생성 입력 ≤ 2개
- [ ] 초대 링크가 화면에 **보이고 복사되고**, 복사 완료 텍스트가 뜬다
- [ ] 초대 링크로 들어온 참여자가 참여하면 **주최자 화면의 참여자 목록에 반영**된다
- [ ] 파티 0개 빈 상태에 안내 카피가 있다
- [ ] 파티 종료 후 다음 행동(재방문 트리거)이 화면에 있다

### 문서
- [ ] 타깃에 **실명 수준의 집단 + 인터뷰/관찰 인용 + 날짜**가 있다 (B1 상한 해제)
- [ ] 첫 100명: **커뮤니티 고유명사 · 모수 · 실행자 · 날짜** 중 둘 이상 (B2 상한 해제)
- [ ] "왜 초대 없이는 안 되는가" 한 문장 (B3)
- [ ] 리텐션 트리거의 **시점·조건**과 구현 위치 (B4 상한 해제)
- [ ] 대체재를 **이름으로** 지목하고 못 하는 점을 짚었다 (C3 상한 해제)
- [ ] "계획이다/예정이다/하면 된다" 문장 0개
- [ ] 기획안에 쓴 기능 = 앱에서 실제로 눌러지는 기능

## 6. 이 페르소나 기준 예상 감점 시나리오

| 상황 | 예상 |
|---|---|
| 초대 기능은 있지만 혼자서도 완결되는 제품 | B3 5점 근처 |
| 타깃을 "대학생"으로만 쓴 문서 | B1 3~4점 |
| 유입 채널에 "인스타·에브리타임" 이름만 | B2 4~5점 (상한 5) |
| 리텐션 문단이 "알림을 보낸다" | B4 4~5점 (상한 5) |
| 기획안에 "정산 기능" 있는데 앱에 없음 | A3 감점 + 정산에 기댄 B4·C1 6점 상한 |
