# AI 심사관 페르소나 정리본

> 실제 페르소나 프롬프트는 비공개다. 이 폴더는 **공식 루브릭 12항목 + 앵커 + 상한 규칙**과 운영진 설명("실제 창업가·엔지니어·투자자의 경험을 담아 구성")을 근거로 **역설계한 추정본**이다.
> 목적: 코드를 만들고 검증할 때 **세 심사관의 눈으로 자가 채점**해서 제출 전에 구멍을 메운다.

세 페르소나 모두 **12항목 전부**를 채점한다. 다른 건 "무엇을 근거로 인정하느냐"의 렌즈다. 최종 점수는 항목별 중앙값(3회) → 페르소나 평균이므로 **한 페르소나에게만 잘 보이면 1/3만 오른다.** 세 렌즈를 모두 통과하는 근거를 만든다.

## 사용법 — 자가 심사 루틴

1. 앱 배포 + 기획안·스크립트 초안이 나오면, 팀원 3명이 각자 페르소나 파일 하나씩 맡는다
2. 각자 파일의 **"자가 점검표"** 를 배포 URL과 문서로 실제로 돌린다 (브라우저로 3단계 직접 실행 포함)
3. 아래 가채점표에 0~10점을 적는다. 앵커: 0 / 5 / 10, 상한 규칙 적용 (근거 없으면 5, 미구현 기능 근거면 6, 검증 실패 기능 근거면 4)
4. **3점 이상 벌어지는 항목**부터 고친다 — 페르소나별로 차이가 크다는 건 근거가 한 렌즈에만 맞춰졌다는 뜻

## 세 페르소나 공통으로 적용하는 규칙 (루브릭 원문)

- **의도 ≠ 근거**: "~할 계획/예정/하면 된다"는 5점 상한
- **구현 대조**: 문서가 주장한 기능이 브라우저에서 확인 안 되면 그 주장에 기댄 B·C는 6점 상한, 명시적 실패면 4점 상한
- **분량 무관**: 길게 쓴 팀과 짧게 쓴 팀은 같은 점수
- **7점 이상은 인용 가능한 구체 근거가 있을 때만**. B·C는 4~6이 정상 분포
