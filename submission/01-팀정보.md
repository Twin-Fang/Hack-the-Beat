# 팀 정보 · 서비스 URL — 제출 폼 붙여넣기용

> 팀 코드(체크인 시 발급받은 6자리)는 **이 파일을 포함해 레포 어디에도 적지 않는다.**
> 제출 사이트 `/login`에서 입력할 때만 쓴다.

## 1. 팀 이름 (필수 · 60자)

```
Hack the Beat
```

> **제출 전 확인**: 리포트에 표시될 이름이고 **제출과 동시에 확정, 이후 변경 불가**다.
> 발표 스크립트가 "팀 Hack the Beat"로 자기소개하므로 다른 이름으로 낼 거면 스크립트도 같이 고친다.

## 2. 서비스 URL (필수)

```
https://twin-fang.github.io/Hack-the-Beat/
```

- 끝 슬래시 포함. 에이전트는 이 주소에서 출발하고, 첫 화면이 곧 1단계 시작점이다.
- 제출 직전 **시크릿 창**에서 열어 3단계를 손으로 한 번 완주한다 (localStorage가 비어 있는 상태가 에이전트와 같은 조건이다).
- 제출 후 **배포 프리즈**. 심사 시점에 열리는 화면이 채점 대상이다.

## 3. 테스트 계정 (선택)

```
아이디: (비움)
비밀번호: (비움)
```

- 비워두면 에이전트가 로그인을 시도하지 않고 비로그인 범위만 검증한다. 우리 핵심 플로우는 **로그인이 없다**.
- 스캐폴드에 남아 있던 로그인 가드는 제품 경로에서 제거돼 있다. 첫 화면(`/`)이 바로 파티 생성 화면이다.

## 4. 확인 체크박스

- "제출 후 수정할 수 없음을 확인했습니다" — 팀원 전원이 [README](./README.md) 직전 체크리스트를 같이 본 뒤 **한 명만** "제출하고 심사 시작"을 누른다.
