# 핵심 플로우 3단계 — 제출 폼 붙여넣기용

> 폼의 3개 입력란에 아래 세 줄을 **그대로** 복사한다. 에이전트가 이 문장을 순서대로 실행하며,
> 단계별 성공·실패가 A1(실효 13.6%)의 유일한 근거다.
> 문장의 모든 따옴표 문구는 배포 화면의 DOM 텍스트와 글자 단위로 일치한다 (검증 결과: 5절).

## 1단계

```
첫 화면에서 "파티 이름"에 "금요일 파티"를 입력하고 "파티 만들기" 버튼을 누른다. "초대 링크가 생성되었습니다"가 보이고 주소가 /party/로 바뀌면 성공
```

## 2단계

```
"초대 링크 복사" 버튼을 누른다. "복사되었습니다"가 보이고 화면에 초대 링크(URL)가 표시되면 성공
```

## 3단계

```
표시된 초대 링크로 접속해 "이름"에 "김서준"을 입력하고 "참여하기"를 누른다. "참여 완료"와 "만난 사람 1명", "첫 만남"이 보이면 성공
```

## 4. 화면 텍스트 대조표

시나리오에 쓴 문구가 실제 어느 요소에 있는지. 하나라도 어긋나면 에이전트가 요소를 찾지 못한다.

| 단계 | 시나리오 문구 | 화면 요소 | 소스 |
|---|---|---|---|
| 1 | `파티 이름` | `<label for="partyName">` + `<input aria-label="파티 이름">` | `HomePage.tsx` |
| 1 | `파티 만들기` | `<button type="submit">` (화면에서 유일) | `HomePage.tsx` |
| 1 | `초대 링크가 생성되었습니다` | 토스트 + 패스포트 화면 상시 문구 | `HomePage.tsx` · `PartyPassportPage.tsx` |
| 2 | `초대 링크 복사` | `<button data-testid="copy-invite-btn">` | `PartyPassportPage.tsx` |
| 2 | `복사되었습니다` | 토스트 (3초) | `PartyPassportPage.tsx` |
| 2 | 초대 링크(URL) | `?party=<파티코드>&from=<태그코드>` 형태의 전체 URL을 텍스트로 노출 | `PartyPassportPage.tsx` |
| 3 | `이름` | `<label for="participantName">` + `<input aria-label="이름">` | `PartyPassportPage.tsx` |

## 5. 실측 검증 결과 (2026-08-29, 헤드리스 Chromium)

3단계를 심사 에이전트와 같은 방식(헤드리스 브라우저 조작)으로 데스크톱·모바일에서 각각 완주시켰다.

| 뷰포트 | 1단계 | 2단계 | 3단계 | 콘솔 에러 |
|---|---|---|---|---|
| 데스크톱 1280×720 | 통과 — `/party/MS3Y6Q` 이동, 완료 문구 노출 | 통과 — `복사되었습니다` + 초대 링크 노출 | 통과 — `참여 완료` · `만난 사람 1명` · `첫 만남 획득 완료` | 0건 |
| 모바일 375×812 | 통과 — `/party/AVUYS7` 이동 | 통과 | 통과 — 판정 문구 4종 전부 `true` | 0건 |

검증 중 발견해 고친 실패 지점 (모두 수정 완료):

1. **버튼 이름 중복** — 파티 생성이 모달이라 "파티 만들기"가 화면에 2개 존재했다. 텍스트로 버튼을 찾으면 중복 매칭돼 클릭이 실패했다. → 모달을 없애고 첫 화면 인라인 폼으로 바꿔 화면에 하나만 남겼다.
2. **초대 링크 재진입 차단** — 초대 링크를 만든 브라우저에서 그 링크를 열면 기존 세션이 잡혀 참여 등록 화면이 뜨지 않았다. 3단계가 통째로 실패하는 경로였다. → 초대자 코드가 붙어 있으면 세션과 무관하게 등록 화면을 먼저 보여준다.
3. **비활성화 버튼** — 입력값이 비면 버튼이 `disabled`라, 입력이 한 번 어긋나면 플로우가 그대로 멈췄다. → 항상 누를 수 있게 하고 사유를 화면에 안내한다.
4. **완료 문구 소실** — 완료 텍스트가 토스트에만 있어 3초 뒤 사라졌다. → `초대 링크가 생성되었습니다`·`참여 완료`를 화면에 상시 노출한다.

## 6. 나머지 폼 항목

- **테스트 계정 아이디 / 비밀번호**: 비워둔다. 로그인 없이 1단계부터 완주된다.
- **확인 포인트**: 2~3단계가 초대·동반 참여(파티형 확산 구조, B3 실효 9.9%)의 실제 동작이다. 3단계에서 `만난 사람 1명`이 되는 것이 초대자–참여자 상호 태그가 서버에서 생성됐다는 증거다.
